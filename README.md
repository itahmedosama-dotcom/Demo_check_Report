# NSH Report - نسخة HTML/JS ثابتة

هذه نسخة مُحوَّلة بالكامل من المشروع الأصلي (PHP) إلى HTML + JavaScript ثابت، عشان تشتغل مباشرة على GitHub Pages من غير الحاجة لاستضافة PHP.

## ⚠️ تحذير أمني مهم — اقرأه قبل النشر

النسخة الأصلية (PHP) كانت بتخبي مفتاح الاتصال بـ Google Sheets (`SHEETS_API_KEY`) وعمليات التحقق من الباسورد على السيرفر، فمفيش حد بره المشروع يشوفها.

في النسخة دي (الثابتة)، **كل حاجة بقت شغالة داخل متصفح الزائر نفسه**، وده معناه:

- أي حد يفتح الموقع يقدر يشوف رابط ومفتاح Google Apps Script (`js/config.js`) بسهولة من View Source أو Developer Tools.
- بالمفتاح ده، أي حد يقدر يقرأ أو يعدّل **كل التقارير وكل بيانات المستخدمين** (بما فيها كلمات السر، لأنها متخزنة كنص عادي) مباشرة من الـ Apps Script، حتى من غير ما يمر بصفحة تسجيل الدخول أصلًا.
- تسجيل الدخول نفسه بيتم عن طريق تحميل كل المستخدمين وكلمات سرهم في متصفح الزائر ومقارنتها — يعني كلمات السر بتتبعت لأي حد بيحاول يسجل دخول.

يعني عمليًا: **الحماية الحالية شكلية فقط**، مش حماية حقيقية. لو فيه بيانات حقيقية لأشخاص (باسبورات، أرقام تليفونات) هتتخزن في المشروع ده، الأفضل إنك:
- تحط المستودع (Repository) على GitHub كـ **Private**، و
- متنشرش الموقع كـ GitHub Pages عام لو البيانات حساسة، أو
- ترجع للنسخة الأصلية PHP وتستضيفها على سيرفر PHP حقيقي (زي الموضح في المشروع الأصلي SETUP_AR.md) — دي الطريقة السليمة أمنيًا.

## خطوات النشر على GitHub Pages

1. أنشئ مستودع جديد على GitHub (يفضل Private لو فيه بيانات حقيقية).
2. من داخل مجلد المشروع:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin <رابط_المستودع_من_GitHub>
   git push -u origin main
   ```
3. من إعدادات المستودع (Settings > Pages)، اختر Branch: `main` و Folder: `/ (root)`، ثم Save.
4. بعد دقيقة أو اثنين، الموقع هيبقى شغال على رابط زي:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## تحديثات جديدة

- تم توحيد هوية الموقع بألوان لوجو "مجمع نهج الشفاء الطبي العام" (أخضر / أزرق / برتقالي)، وإضافة اللوجو في هيدر كل الصفحات.
- تمت إضافة صفحة **`analytics.html`** — داشبورد تحليلي بعد تسجيل الدخول، فيه: إجمالي التقارير، نسبة Valid/Not Valid، تقارير اليوم والأسبوع، رسم بياني يومي (آخر 14 يوم)، توزيع الحالة، عدد التقارير حسب كل مستخدم، وآخر 10 نشاطات. يظهر رابطه في أعلى صفحة `dashboard.html`.
- تم تعديل صفحة البحث العام (`view.html`) بحيث يكون **رقم الباسبور/الإقامة هو الحقل الوحيد المطلوب**، والتاريخ ورقم التليفون أصبحا اختياريين ويُستخدمان فقط لتضييق نتائج البحث لو المستخدم عايز يدقق أكتر.
- الجداول أصبحت قابلة للتمرير أفقيًا على الشاشات الصغيرة (موبايل)، وحالة التقرير بقت تظهر كشارة (badge) ملوّنة بدل نص عادي.

## ملاحظات

- الإعدادات (رابط Apps Script والمفتاح السري) موجودة في `js/config.js`.
- لو غيّرت مفتاح `API_KEY` في `Code.gs` (الموجود على Google Apps Script)، لازم تغيّره بنفس القيمة هنا في `js/config.js`.
- تأكد إن نشر Apps Script (Deploy > Manage deployments) شغال بصلاحية `Anyone` عشان الموقع الثابت يقدر يوصله من أي متصفح.
- ملفات `.php` الأصلية اتشالت من النسخة دي؛ لو حبيت ترجع للنسخة PHP الأصلية، هتلاقيها في الملف اللي رفعته في البداية.
