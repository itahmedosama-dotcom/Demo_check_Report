إعدادات زر واتساب

حط رقم واتساب التواصل هنا عشان يظهر زرار "تحدث معنا" في كل صفحات الموقع. سيبه فاضي لو عايز تخفي الزرار مؤقتًا.

إعدادات حقوق الملكية (الفوتر)

النص وبيانات التواصل اللي بتظهر في أسفل كل صفحات الموقع. سيب أي حقل فاضي لو عايز ترجع للقيمة الافتراضية بتاعته.

🎨 هوية الشركة (الشعار / الاسم / الألوان)

استخدم القسم ده عشان تخصّص شكل الموقع باسم وشعار وألوان أي شركة تانية بتستخدم نفس المشروع، من غير أي تعديل في الكود. سيب اسم الشركة فاضي أو رجّع الألوان الافتراضية لو عايز ترجع للهوية الأصلية.

هذا القسم متاح فقط لحساب الأدمن.

بيتم تصغير الصورة تلقائيًا وتخزينها جوه إعدادات الموقع؛ لو الصورة كبيرة جدًا هيظهر تنبيه يطلب صورة أصغر.

🔗 ربط Google Sheet / Apps Script

غيّر رابط ومفتاح Google Apps Script هنا لو عايز تربط نفس المشروع بشيت جديد (شركة تانية مثلاً)، من غير ما تفتح أي كود يدويًا.

⚠️ زرار "تطبيق ومعاينة" بيغيّر الاتصال على متصفحك أنت بس (على هذا الجهاز)، مش على باقي الموظفين أو الزوار. عشان التغيير يشتغل لكل زوار الموقع بشكل دائم، لازم تدوس "تحميل ملف config.js المحدّث" وترفع الملف الناتج بدل js/config.js الحالي في نفس مكان استضافة الموقع (مثلاً GitHub Pages).

🔌 ربط مزودي خدمة خارجيين (SMS / WhatsApp API)

إعدادات ربط مزود إرسال SMS و/أو WhatsApp Business API. بعد تعبئة البيانات وتفعيل المزود، هيظهر زرار إرسال فعلي وتلقائي (📤 / 📩) بجانب كل تقرير في لوحة التحكم، بيبعت الرسالة مباشرة للعميل من غير أي خطوة يدوية. الإرسال بيحصل من Apps Script نفسه (مش من المتصفح) عشان توكن/مفتاح المزود يفضل مخبّى.

📩 مزود SMS

💡 لو المزود Twilio: اكتب في "المفتاح السري" كده بالظبط: AccountSid:AuthToken (يعني الاتنين مفصولين بـ :)، وفي "اسم/رقم المرسل" رقم Twilio بتاعك (مثال: +15551234567).

💬 WhatsApp Business API

💡 Meta Cloud API (الافتراضي): سيب "اسم المزود" فاضي أو اكتب Meta، والتوكن هو الـ Access Token من Meta for Developers، ومعرّف رقم الهاتف هو الـ Phone Number ID بتاعك. لو Twilio: اكتب Twilio في "اسم المزود"، وفي التوكن اكتب AccountSid:AuthToken، وفي معرّف رقم الهاتف اكتب رقم واتساب Twilio (مثال: +15551234567).

⚠️ زي باقي إعدادات الموقع الثابت ده: أي مفتاح API بتحفظه هنا هيكون ظاهر لأي زائر يفتح كود الصفحة (View Source)، بالظبط زي مفتاح Google Sheets الحالي. متحطش هنا مفاتيح حساسة لحسابات فيها بيانات دفع أو صلاحيات واسعة.

💾 نسخة احتياطية كاملة

يحمّل ملف Excel واحد فيه كل بيانات النظام (التقارير، المستخدمون، الإعدادات، طلبات التسجيل) كنسخة احتياطية على جهازك.
